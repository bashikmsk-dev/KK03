# Кибер Кино — сайт международного фестиваля ИИ-короткого метра

Статический сайт: HTML, CSS и обычный JS. Сборка **не обязательна** — файлы
самодостаточны, их можно просто открыть в браузере или положить на любой хостинг.
Для удобной разработки сверху подключён Vite (дев-сервер с автообновлением и
минифицированная сборка).

## Быстрый старт

Нужен [Node.js](https://nodejs.org) версии 20.19 или новее (проверить: `node -v`).
Работает одинаково на Windows, macOS и Linux.

```bash
git clone https://github.com/bashikmsk-dev/KK03.git
cd KK03
npm install
npm run dev
```

Откроется адрес `http://localhost:5173`. Правки в HTML, CSS и JS подхватываются сразу.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | дев-сервер на `http://localhost:5173` |
| `npm run build` | минифицированная сборка в папку `dist/` |
| `npm run preview` | посмотреть собранный `dist/` на `http://localhost:4173` |

**Без Node.js.** Сайт открывается и так: скачайте репозиторий и откройте `index.html`
двойным кликом. Именно поэтому скрипты подключены как обычные, а не как ES-модули —
модули браузер по протоколу `file://` не загружает.

### Имена жюри внутри картинки

Имя каждого члена жюри выводится текстом прямо в белой плашке на его карточке —
это не часть изображения, а HTML. Положение плашки задаётся в `index.html`
и `en/index.html` тремя переменными в атрибуте `style` карточки:

```html
<div class="juror reveal" style="--img-w: 67%; --plate-y: 70.4%; --plate-w: 75%">
```

- `--plate-y` — центр белой плашки по вертикали, в % от высоты картинки;
- `--plate-w` — ширина текстового блока, в % от ширины картинки;
- `--img-w` — ширина самой картинки в колонке; стоит только у квадратных снимков,
  чтобы все карточки в ряду были одной высоты.

Если замените фото жюри на другое — поправьте эти три числа у нужной карточки.

## Эффект на титульном экране

Базово виден `enshtane-01.png`. При наведении курсора вокруг него остаётся «дыра», а вся
остальная площадь проявляется как `enshtane-02.png`.

Режим переключается одной строкой в начале `assets/js/hero.js`:

```js
const REVEAL_MODE = 'outside'; // 'outside' — 02 проявляется ЗА областью курсора
                               // 'lens'    — 02 виден только в круге ПОД курсором
```

Там же настраиваются размер круга (`REVEAL_RADIUS`, `RADIUS_MIN`, `RADIUS_MAX`) и
инерция движения (`EASE`). На телефонах и планшетах, где курсора нет, маска плавно
движется сама. При системной настройке «уменьшить движение» эффект отключается.

## Публикация на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions**.
2. Влейте ветку в `main` — воркфлоу `.github/workflows/pages.yml` соберёт проект
   (`npm ci && npm run build`) и опубликует папку `dist/`.

Можно и без сборки: Source → **Deploy from a branch**, ветка и папка `/ (root)`.
Файл `.nojekyll` в корне уже лежит, сайт отдастся как есть.

## Временные картинки

```bash
pip install pillow
python3 tools/make_placeholders.py
```

Скрипт создаёт заглушку только там, где файла ещё нет, — настоящие картинки он не
трогает. Чтобы перерисовать заглушку, удалите её и запустите скрипт снова.
